# Drexel Rocket Team 🚀

Student rocketry at Drexel University. We design, build, and test liquid rocket engines, along with the avionics and ground software that run them.

## What we're working on

| Project | What it is |
| --- | --- |
| **Ambition-1** | Our first engine, plus its test stand: ground control, LoRa telemetry, servo valve control, and data logging |
| **Dragon-1** | Our first pump-fed, regeneratively cooled engine |

Our repositories are private to team members.
